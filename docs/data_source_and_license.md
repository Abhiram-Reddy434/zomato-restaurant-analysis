- **Kaggle Publisher/Uploader:** Himanshu Poddar
- **Underlying Data:** Zomato Bengaluru restaurant listings

- **Licence Displayed on Kaggle:** Data files © Original Authors

## 2. Licence and Redistribution

The dataset is publicly accessible through Kaggle. However, its displayed licence identifies the original authors as copyright holders.

Public availability does not automatically grant permission to redistribute the dataset or use it commercially.

The original CSV is therefore not included in this repository. Users should review the dataset's terms and applicable rights before downloading, reusing or redistributing it.

## 3. Data Handling

The original dataset is stored locally at:

`data/raw/zomato.csv`

The analysis notebook reads the dataset from this location.

The raw CSV is excluded from Git tracking to avoid unintentionally publishing data whose redistribution rights have not been established.

## 4. Dataset Limitations

- The dataset represents historical restaurant listings from Bengaluru.
- Restaurant information, ratings, prices and service availability may have changed since the data was collected.
- The dataset should not be treated as a representation of the current restaurant market.
- Missing, inconsistent and outdated records may affect the analysis.
- Relationships identified in the analysis do not necessarily establish causation.
