
# Raw Dataset

This directory stores the original Zomato Bengaluru restaurant dataset used in this project.

## Dataset Download

The dataset can be obtained from Kaggle:

https://www.kaggle.com/datasets/himanshupoddar/zomato-bangalore-restaurants

## Required File

- **Filename:** `zomato.csv`
- **Expected location:** `data/raw/zomato.csv`

## Setup Instructions

1. Visit the Kaggle dataset page.
2. Download the dataset after reviewing its usage terms.
3. Extract the downloaded archive, if necessary.
4. Place the original CSV in this directory.
5. Ensure the filename is `zomato.csv`.

The analysis notebook expects the dataset at:

`data/raw/zomato.csv`

## Note

The original CSV is not included in this public repository. Users must obtain their own copy from the dataset source.
